# Budget Buddy - Phase 1.2 Starter (HTML/CSS/JS)

Minimal prototype for CMSC434 Phase 1.2 with required six bottom tabs:

- Text (scrollable long text)
- LR ("Down Here" in lower-right)
- Colors (required color lines + pie chart)
- Profile (centered image + dismissible notification)
- Choices (radio + dropdown + output button)
- ToDo (add + cross off + delete)

## Run

- Open `index.html` directly in Chrome.
- The app is sized to `640x960` for the course device spec.

## Eclipse

- In Eclipse: `File -> Import -> General -> Existing Projects into Workspace`
- Select this folder (`budget-buddy`) and import.
- Open `index.html` in Eclipse and run/open in browser.

No server or external dependencies are required.
